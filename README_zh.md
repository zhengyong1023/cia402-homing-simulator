# CiA 402 回零模式交互式仿真器

[English](README.md) | [简体中文](README_zh.md)

> 🚀 **在线运行 (Live Demo)**：[https://zhengyong1023.github.io/cia402-homing-simulator/](https://zhengyong1023.github.io/cia402-homing-simulator/)

专为运动控制工程师、固件开发人员及自动化工程师设计的交互式 Web 仿真工具，用于可视化学习、验证与调试 **CiA 402 (CANopen / EtherCAT)** 协议中的各类回零方式（Homing Methods）与状态机跳转逻辑。

---

## 📌 项目概述

**CiA 402 回零模式仿真器** 基于 **CiA 402（CANopen 设备子协议：驱动器与运动控制）** 与 **ETG.6010** 规范，提供了一个纯前端的可视化物理与逻辑测试环境。

在物理伺服驱动器与机械机构上调试回零逻辑通常耗时繁琐、缺乏直观的可视化手段，且容易因配置不当造成机械碰撞。本工具在现代浏览器内实现了真实的物理动力学模拟（加速度、减速度、速度切换、传感器边沿锁存及机械堵转检测），**无需安装任何运行时或第三方依赖**。

## ✨ 核心特性

- **全面的 CiA 402 回零方法覆盖**：
  - **机械堵转 / 碰硬限位回零（方法 -6 ~ -1）**：低速/高速碰硬停止、释放扭矩反向脱开以及堵转后寻 Z 相脉冲。
  - **限位开关 + 索引脉冲（方法 1, 2）**：撞限位反转、检测限位开关边沿并锁存编码器 Z 相（Index）脉冲。
  - **原点开关 + 索引脉冲（方法 3 ~ 6）**：针对原点开关开/关初始状态的正反向寻边并锁存 Z 相脉冲。
  - **限位开关 + 原点开关 + 索引脉冲（方法 7 ~ 14）**：遭遇极限位置反向脱开，结合原点开关与 Z 相脉冲完成精准定位。
  - **仅开关边沿回零（方法 17 ~ 30）**：无需编码器 Z 相，直接以限位或原点开关的有效/无效跳变沿作为零点。
  - **仅 Z 相脉冲与当前位置清零（方法 33, 34, 35/37）**：纯编码器 Z 脉冲搜索，或无需电机转动的直接当前位置标定。

- **实时物理动力学与传感器仿真**：
  - 平滑的梯形加减速运动曲线（Trapezoidal Profile）。
  - 动态模拟 **负限位 (`NOT / L-`)**、**正限位 (`POT / L+`)**、**原点开关 (`HOME`)**、**编码器 Z 相脉冲 (`INDEX`)** 以及 **机械碰硬堵转 (`STALL`)**。
  - 直观的状态指示 LED 与物理坐标标尺。

- **诊断面板与高精度事件日志**：
  - 高频遥测数据：实时位置坐标、瞬时速度、运动方向、原始传感器电平及 CiA 402 主状态/子状态机。
  - 毫秒级时间戳事件日志，详尽记录加速、减速、反向、信号沿跳变、触发锁存及完成/报错全过程。

- **高内聚低耦合的代码架构**：
  - 纯 JavaScript 实现的核心逻辑层（`homing-logic.js`），与 DOM 完全解耦，便于移植或集成进其他自动化测试框架。
  - 基于 Tailwind CSS 构建的现代深色主题响应式交互界面。

- **开箱即用，纯客户端运行**：
  - 原生支持 Google Chrome、Microsoft Edge、Mozilla Firefox、Safari 等主流浏览器。
  - 无需 Node.js、后端服务或编译构建流程。

## 🕹️ 界面布局与操作指南

### 1. 运动轴工作台 (Motion Axis Stage)
- **滑块滑台 (蓝色滑块)**：可视化滑台在有效机械行程（$0 \sim 1000\text{ u}$）内的实时位移。
- **传感器状态灯 (顶部 LED)**：
  - 🔴 **POT (L+)**：正向硬件限位触发。
  - 🔴 **NOT (L-)**：负向硬件限位触发。
  - 🟢 **HOME**：原点开关信号有效。
  - 🟡 **Z (INDEX)**：编码器零位（Z 相）脉冲捕获。
  - 🟣 **STALL**：机械碰硬或达到堵转力矩阈值。

### 2. 控制面板 (Control Panel)
- **回零方式 (Homing Method)**：按信号触发类型分类的标准化方法下拉列表。
- **初始位置预设 (Initial Position)**：滑台初始起始点（如 `原点左侧`、`位于原点上`、`原点右侧`、`靠近限位`、`位于限位上`）。
- **快调速度 (`HomingVelHigh`)**：大范围搜寻开关时的高速运动速度 ($10 \sim 200\text{ u/s}$)。
- **爬行速度 (`HomingVelLow`)**：用于精确定位寻边和捕获 Z 相时的低速爬行速度 ($5 \sim 100\text{ u/s}$)。
- **操作按钮**：
  - `▶ 启动 (Start)`：根据当前选择的回零方法开始执行状态机运动。
  - `↺ 重置 (Reset)`：终止当前运动，恢复轴到初始设定状态。

### 3. 诊断与遥测 (Diagnostics & Telemetry)
- **诊断面板**：实时刷新物理坐标 ($u$)、线速度 ($u/s$)、运行方向、实时电平及 CiA 402 主状态 (`IDLE`、`SEARCH_LIMIT`、`SEARCH_HOME`、`SEARCH_INDEX`、`BACK_OFF`、`HOMED`、`ERROR`)。
- **运行日志 (Event Log)**：按时间顺序记录关键物理与状态机事件。

## 📋 支持的 CiA 402 回零模式对照表

| 分类 | 模式编号 | 逻辑说明 |
| :--- | :---: | :--- |
| **机械堵转 / 碰硬限位** | `-6` | 负向低速运行直至碰硬堵转 $\rightarrow$ 停止并置零 |
| | `-5` | 正向低速运行直至碰硬堵转 $\rightarrow$ 停止并置零 |
| | `-4` | 负向高速运行碰硬 $\rightarrow$ 反向微调脱开力矩区 $\rightarrow$ 停止并置零 |
| | `-3` | 正向高速运行碰硬 $\rightarrow$ 反向微调脱开力矩区 $\rightarrow$ 停止并置零 |
| | `-2` | 负向运行碰硬 $\rightarrow$ 反向脱开力矩区 $\rightarrow$ 寻找首个 Z 相脉冲 |
| | `-1` | 正向运行碰硬 $\rightarrow$ 反向脱开力矩区 $\rightarrow$ 寻找首个 Z 相脉冲 |
| **限位开关 + 索引脉冲** | `1` | 负向运行触发负限位 $\rightarrow$ 反向脱开限位沿 $\rightarrow$ 捕获首个 Z 相脉冲 |
| | `2` | 正向运行触发正限位 $\rightarrow$ 反向脱开限位沿 $\rightarrow$ 捕获首个 Z 相脉冲 |
| **原点开关 + 索引脉冲** | `3` | 正向初始搜索，原点开关 + Z 相脉冲（Z 点位于原点开关外） |
| | `4` | 正向初始搜索，原点开关 + Z 相脉冲（Z 点位于原点开关内） |
| | `5` | 负向初始搜索，原点开关 + Z 相脉冲（Z 点位于原点开关外） |
| | `6` | 负向初始搜索，原点开关 + Z 相脉冲（Z 点位于原点开关内） |
| **限位 + 原点 + 索引脉冲** | `7` ~ `10` | 正向初始搜索，撞正限位自动折返，结合原点开关与 Z 相定位 |
| | `11` ~ `14` | 负向初始搜索，撞负限位自动折返，结合原点开关与 Z 相定位 |
| **限位开关边沿 (无 Z)** | `17` | 负限位跳变沿检测（停在限位信号离开沿，无需 Z 脉冲） |
| | `18` | 正限位跳变沿检测（停在限位信号离开沿，无需 Z 脉冲） |
| **原点开关边沿 (无 Z)** | `19`, `20` | 正向搜索原点开关进入/离开沿（无需 Z 脉冲） |
| | `21`, `22` | 负向搜索原点开关进入/离开沿（无需 Z 脉冲） |
| **限位 + 原点边沿 (无 Z)** | `23` ~ `26` | 正向初始搜索，遇限位折返搜索原点开关跳变沿 |
| | `27` ~ `30` | 负向初始搜索，遇限位折返搜索原点开关跳变沿 |
| **仅索引脉冲** | `33` | 负向低速运行，寻找首个 Z 相脉冲 |
| | `34` | 正向低速运行，寻找首个 Z 相脉冲 |
| **即时当前位置标定** | `35` / `37` | 直接将当前物理位置标定为零点（电机不动作） |

## 📂 仓库代码组织

```text
├── index.html                        # GitHub Pages 访问入口（自动跳转至模拟器）
├── src/
│   ├── cia402-homing-simulator.html   # 主 Web 界面（UI 交互、Canvas 渲染与样式布局）
│   └── homing-logic.js               # 核心回零状态机与物理动力学引擎（纯 JS）
├── LICENSE                           # MIT 开源授权协议
├── README.md                         # 英文版项目文档 (English)
└── README_zh.md                      # 中文版项目文档 (简体中文)
```

### 架构亮点
- **职责分离**：
  - `homing-logic.js` 封装了所有物理动力学计算（梯形加减速曲线、边界刚性约束）与 CiA 402 状态机运转，通过标准回调（`log()`、`setState()`、`completeHoming()`、`triggerError()`）与外部通信。
  - `cia402-homing-simulator.html` 专注于 DOM 交互、参数配置绑定、Tailwind CSS 样式呈现以及通过 `requestAnimationFrame` 驱动的动效渲染循环。
